## Bilibili Video Timer
本拓展用于在 Bilibili 视频播放页计算本集或分集/合集的剩余时长、自定义区间总时长，并为分集视频添加标记。

本文使用说明对应本仓库 `main` 分支。商店版本、原项目 Release 和已有安装包可能尚未包含这些更新，体验当前功能请从本仓库源码加载。

🍟 **欢迎大家在Github/Issues或拓展选项页的`反馈`中提出建议和bug(v2.0.2+可用)**

❗ 注意：**v3.0.0+**版本支持**Bilibili视频播放页面-分集视频、合集视频**(`https://www.bilibili.com/video/*`)

❗ ❗ 由于B站修改了页面元素，**因此v2.1.1及以前版本出现无法使用的情况**，解决方法参见：<a href="https://github.com/Whimmey/BiliBiliTimer/issues/9#issuecomment-2425410003" target="_blank">Issues#9</a>

### 安装
<font color=orange>**本项目已经上架微软商店**</font>. 点击右侧`About`中的<a href="https://microsoftedge.microsoft.com/addons/detail/bilibili-video-timer/kjginbekfcfdnfjhnophpcdjoojnfabn" target="_blank">microsoftedge链接</a>可直接跳转到免费安装（由于审核速度问题，版本会比Git**滞后**）.

体验本仓库当前功能：

1. [下载扩展压缩包](https://github.com/28TheCat/BiliBiliTimer/raw/refs/heads/main/build/BiliBiliTimer-main.zip)并解压；也可在[本仓库](https://github.com/28TheCat/BiliBiliTimer)下载 `main` 分支源码或克隆仓库。
2. 在 Chrome 或 Edge 的扩展管理页面开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目根目录。
4. 打开 Bilibili 视频播放页；更新或重新加载扩展后，请刷新已经打开的视频页。

旧版安装包仍可通过[原项目 Release](https://github.com/Whimmey/BiliBiliTimer/releases)获取，功能以对应版本为准。

### 使用
在 Bilibili 视频播放页，点击浏览器工具栏中的扩展图标，或点击页面右侧的悬浮球，即可打开计时面板。

#### 计算范围与剩余时长

面板顶部提供「本集｜全部分集」切换，首次默认选择「全部分集」，之后记住上次选择。单个视频自动按本集计算，并隐藏切换和集数输入。

| 范围 | 计算内容 | 进度含义 |
| --- | --- | --- |
| 本集 | 当前播放位置到本集结束的剩余时长 | 本集已播放的比例 |
| 全部分集 | 默认从当前播放位置计算到最后一集；合集仅计算当前分组 | 当前集之前各集的时长，加上本集已播放时长，占整个列表的比例 |

- 「本集」模式隐藏起止集数、滑块和「还原」按钮。
- 「全部分集」模式默认起始集为当前集，结束集为最后一集。修改任一集数后，改为计算包含首尾集的**完整区间时长**，不扣除本集已播放部分。
- 聚焦「从」或「到」输入框后，滑块会调整对应的起始集或结束集；两个输入值不分先后，计算时会自动排序。
- 点击「还原」回到从当前播放位置到最后一集的默认计算方式。
- 面板打开或点击「计算」时读取播放位置；面板内的结果不会随播放每秒刷新。切换范围会读取最新播放位置，并复用已有的时长数据。
- 同一列表内切集时会更新列表进度；要获取新一集的实际播放位置和剩余时长，请点击「计算」。

这里的「进度」按列表顺序累计时长，不会记录每集是否实际看完；显示时长也未按播放倍速折算。

#### 悬浮球与显示设置

- 悬浮球通过水波和百分比显示进度，跟随「本集／全部分集」模式，每秒读取页面播放器的位置。
- 点击悬浮球展开计时面板，点击关闭按钮或按 Esc 收起；拖动悬浮球或展开面板的标题栏可调整位置。
- 右键工具栏中的扩展图标，进入「扩展选项」，可以设置显示开关、20%～100% 的不透明度、全屏播放时是否隐藏，以及重置位置。
- 默认显示悬浮球，全屏时默认隐藏。显示设置会应用到已打开的视频页，不透明度只影响悬浮球，展开的面板保持清晰。

#### 右键菜单-关于视频选集标记功能

在分集列表的视频链接上右键，选择「标记一下」，即可添加默认标记 ✨。右键功能目前仅处理当前 BV 的分集链接，合集时长计算不代表支持合集标记。

- 点击已有标记可修改内容；点「取消」或按 Esc 保留原内容，确认空内容则删除标记。
- 在「扩展选项」中可修改默认标记，或通过「查看所有Marker」编辑、保存及清除已有标记。
- 标记保存在浏览器同步存储中。列表延迟加载、重新渲染或站内切换视频时，会尝试恢复对应视频的标记；设置页修改或删除后，视频页也会同步更新。
- 标记中的引号、尖括号等字符按普通文字显示。
- 标记显示依赖 B 站分集列表的页面结构；页面改版可能需要更新适配。

#### 右键菜单-关于右键计算到此时长

在当前视频的分集链接上右键，选择「计算到此时长」，再打开工具栏弹窗或悬浮球面板，即可计算从当前集到目标集的完整区间时长。

所选集数与标签页、BV 号关联，不会套用到其他标签页或其他视频。记录读取后会清理，关闭标签页或重启浏览器也会清理。使用该功能时，面板会切换到「全部分集」模式。

右键选择后不会自动展开面板，需要手动点击扩展图标或悬浮球。

### 常见问题

- **提示刷新视频页**：安装、更新或重新加载扩展后，刷新已打开的 B 站视频页，再打开面板。
- **提示正在读取播放进度**：播放器尚未就绪或正在跳转播放位置时，等待片刻后点击「计算」。
- **请求超时或进度显示 `--%`**：视频信息请求设有 10 秒超时，覆盖请求和响应正文读取。面板可手动重试；悬浮球请求失败后等待 30 秒再尝试。
- **进度与剩余时长看起来不一致**：确认「本集／全部分集」模式，以及是否修改了区间；自定义区间计算完整集数时长，进度仍按所选范围模式显示。
- **同一视频多次打开面板是否重复请求接口**：视频信息在页面内缓存 60 秒，并合并同时发起的相同请求；播放位置每次单独读取。

## 目录结构

```text
├─manifest.json       # 扩展入口、权限和脚本配置
├─popup.html          # 工具栏弹窗与悬浮面板共用的界面
├─popup.js            # 计算范围、区间输入、进度和标签页通信
├─options.html        # 扩展设置与标记管理界面
├─options.js          # 显示设置、菜单设置及标记管理
├─README.md
├─AjaxDemo.html       # 历史接口示例
├─updates.xml         # 原有扩展更新描述
├─build/              # 当前扩展 ZIP 及历史 CRX，源码修改后需重新打包
├─css/                # 样式文件
├─icons/              # 扩展图标
├─img/                # 功能演示图片
└─js/
   ├─background.js    # 标签页按钮状态、右键菜单和临时选集记录
   ├─content.js       # 播放器状态、消息响应和标记恢复
   ├─calTime.js       # 视频信息请求、缓存与超时
   ├─video.js         # 共用的视频列表解析与进度计算
   ├─floating.js      # 悬浮球显示、拖动与面板嵌入
   └─bootstrap.min.js # 设置页使用的界面组件
```
